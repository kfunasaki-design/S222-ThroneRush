Overview

This guide is intended to provide reference strategies for how allied guilds within S222 can coordinate and approach ThroneRush.

The goal is to help guilds understand the overall situation, coordinate their actions, and make informed decisions while avoiding unnecessary conflicts between allied guilds.

This guide presents suggested approaches based on the current game environment and is intended as a reference rather than a set of mandatory rules.

League: 【GuildVS】Bronze League

Before proceeding, make sure you understand the basic rules for Fortress Levels 1–4.

How to Capture a Lv5 Fortress

Starting from Lv5 Fortresses, the number of Guards increases significantly, with 120 Guards assigned to each fortress.

For this reason, requesting support from an allied guild that currently occupies a Lv4 Fortress can make the capture process much smoother.

The most straightforward method is to coordinate the timing of the declarations of war.

【Example】

1. Assign the attacking guild

Guild ①, located near the Lv5 Fortress, will be designated as the guild responsible for capturing the fortress.

After discussing the plan with Guild ② through the alliance site, Guild ① declares war at the agreed-upon time.

2. Delay the supporting guild's declaration of war

Guild ②, which is also located near the fortress, will act as the supporting guild for Guild ①.

Guild ② should declare war later than Guild ①.

※ The exact delay should be discussed and agreed upon between Guild ① and Guild ② in advance.

3. Divide the number of Guards defeated

A Lv5 Fortress has 120 Guards.

The guild that defeats the greater number of Guards will gain the right to occupy the fortress. Therefore, Guild ① must defeat at least 61 Guards.

Guild ② should provide support by covering any remaining attacks that Guild ① is unable to complete on its own.

This method allows Guild ① to secure the occupation rights while Guild ② assists with the remaining attacks, making it possible to efficiently defeat all 120 Guards.

Lv4 Fortress

Fortress Lv4

Target League: No specific GW League requirement.

Please review the basic rules for Fortress Lv1–3 before proceeding.

For Lv4 fortresses, please use the Schedule Coordination calendar on Discord to clearly indicate which fortress your guild plans to attack and when.

If two or more guilds have overlapping plans for the same fortress, please discuss the situation directly with the other guilds and reach an agreement.

If an agreement cannot be reached, priority will be given to the guild that registered its attack plan first.

Lv3 Fortress

Target League: No specific GW League requirement.

  • Please prioritize fortresses located as close as possible to your initial deployment area.
  • Since the number of fortresses is limited, please focus on occupying one fortress only, even when targeting a lower-level fortress.
  • Do not attempt to recapture a fortress already occupied by an allied guild. If recapture is necessary, please negotiate with the occupying guild beforehand.
  • If multiple guilds declare war on the same fortress by mistake, please resolve the conflict by either one guild voluntarily withdrawing or by discussing the situation and agreeing on which guild will withdraw.

FAQ

Q When should I teleport?
A
Please complete the teleport before the event starts.
If you relocate after the event begins, you may not be able to capture the location as planned.
Q Please tell me the number of fortresses for each level.
A
Lv1(38), Lv2(22), Lv3(12), Lv4(7), Lv5(4), Lv6(3), Lv7(1)
Since the number of bases decreases by seven upon reaching Level 4, trading on this site begins at Level 4.
Q What happens to the number of Imperial Guards if the occupation attempt fails?
A
The number of Imperial Guards returns to its original amount.
For example, if you attack a fortress with 90 Imperial Guards and defeat 89 of them, the number will return to 90 if the occupation attempt fails.
Q Which league can challenge each fortress level?
A
The leagues you can challenge depend on your Fortress level.
  • Lv5： Bronze League
  • Lv6： Silver League
  • Lv7： Gold League
Tap the castle to check which leagues you can attack.
